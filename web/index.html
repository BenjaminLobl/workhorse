First-time Windows setup
  1. Install Python 3.12+ and Ollama from their official sites.
  2. Run the included configure-ollama.cmd, then quit and reopen Ollama.
            This disables cloud features and binds Ollama to this computer.
  3. Download the preferred model (or choose the lighter 9B variant):
    ollama pull qwen3.8:27b
  4. Select Find installed models, choose Qwen, then test it. Choose a model that
            advertises tool calling.
The initial download needs internet access. After installation, local inference can
          run offline. Performance and model quality depend on your hardware and model.
27B may offload to RAM on an 11 GB GPU. Use Gemma 4 12B for a faster vision review.
        Disable Design first for non-visual code changes. Larger contexts need more memory.
Model selection is a preference on this browser. Conversations and files live in the
        local data folder.
